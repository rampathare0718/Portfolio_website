Civic Tech Platform

CleanSnap — Architecture & Deep Dive

Project Overview

CleanSnap is an end-to-end civic reporting web application designed to empower citizens to document and report unhygienic public spots, overflowing garbage bins, and illegal dumpsites. Reports are dynamically cataloged with geo-coordinates, timestamps, and image proofs, then piped directly to designated local civic authorities.

Key Engineering Contributions (Resume Specifics)

  • Responsive React Client: Structured modular component hierarchies with efficient state lifting for image capture, upload compression, and live interactive feeds.
  • Node.js & Express.js RESTful APIs: Architected clean controller-service-repository patterns to handle multipart file uploads, geo-tagging queries, and role-based authority dispatching.
  • MongoDB Scalable Storage: Optimized document schemas for issue lifecycle tracking (Submitted → In Review → Dispatched → Resolved), with compound indexing on status and location.

Key System & Usability Highlights

Designed with duplicate submission prevention through geolocation radius filtering and transparent real-time progress pills tracking municipal response stages.

FloatChat — Oceanographic Telemetry & RAG

Project Overview & Team Hackathon Context

Built as part of an engineering team for Smart India Hackathon 2026, FloatChat is an AI-powered conversational platform for discovering, querying, and visualizing global ARGO oceanographic telemetry data (temperature profiles, salinity curves, trajectories, and bathymetric ocean metrics).

Ram Pathare's Direct Ownership & Contributions

  • Frontend & Auth Module Owner: Designed and implemented a responsive React (Vite) + Tailwind CSS web interface with interactive map-based telemetry tracks (Leaflet) and multi-curve scientific plots (Plotly.js).
  • Service Layer Architecture: Structured a resilient client-side service layer (Axios API client, custom hooks, reusable telemetry cards) for real-time float, trajectory, and statistics views.
  • Secure Authentication: Implemented end-to-end user authentication with JWT sessions and role protection.
  • FastAPI & FAISS RAG Pipeline Collaboration: Collaborated closely with backend teammates developing FastAPI endpoints, PostgreSQL with PostGIS extensions for spatial queries, and a FAISS vector index for retrieval-augmented generation.

Interactive Visualization Architecture

Connected interactive ARGO float markers on the Leaflet map with synchronized Plotly.js charts, allowing oceanographers and students to inspect sensor depths and ocean salinity profiles seamlessly.
